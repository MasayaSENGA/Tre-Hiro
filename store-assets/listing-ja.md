# Chrome ウェブストア掲載文（日本語）

このファイルを Chrome ウェブストア デベロッパー ダッシュボードの掲載情報に反映する。

## 商品名

トレひろ

## 概要（132文字以内）

Trello のカード詳細を広げて左右比率を調整。自動化ボタンの常時表示、カードURLのコピー、ラベル色でのカード色付けにも対応（非公式ツール）。

## 詳細な説明

トレひろは、Trello のカード詳細を画面いっぱいに広げ、説明欄とコメント欄の左右の比率を自由に変えられる拡張機能です。カード詳細の下部にカードボタン（自動化）を常に並べたり、カードURLをワンクリックでコピーしたり、ボードのカードをラベルの色で塗り分けたりできます。リストIDの表示、カードの変更履歴を開くボタン、うっかりアーカイブを防ぐショートカット「c」の無効化にも対応しています。

横に長い表や長い説明も、折り返しの少ない広い画面で読めます。

※個人が開発した非公式ツールで、Atlassian とは関係ありません（詳しくは「ご注意」をご覧ください）。

■ できること

【カード詳細を広く】
・幅：ウィンドウの40〜100%（初期値 95%）
・左右の比率：説明欄15〜90%、残りがコメント欄（初期値 40:60）
・説明欄・添付などを左、コメントとアクティビティを右に表示
・コメント欄を閉じると、説明欄側が横いっぱいに広がります

【よく使うボタンを、いつでも1クリックで】
・カード詳細の下部に、画面の「自動化」から開くカードボタンを常に表示（初期値 ON）
・名前・アイコン・並び順はその一覧と同じです。押すとそのボタンが実行され、実行と結果の通知はサイト側が行います
・この表示だけを OFF にすることもできます

【カードURLをコピー】
・カード詳細のヘッダーのボタンから、カードタイトルを含まない短い形式（/c/{カードID}/ まで）のURLをコピーできます

【カードをラベルの色で塗り分け】
・カード全体に、その色を薄く重ねます（複数あるときは1つ目の色）
・左端の細い帯には、付いている色を上から等分に並べます（最大4色）
・色の濃さは5〜45%（初期値 45%）、鮮やかさは0〜200%（初期値 100%）で調整できます
・色付けだけを OFF にすることもできます

【リストIDを表示】
・ボードの各リストの名前の下に、そのリストのIDを表示します（初期値 ON）
・押すとIDをコピーできます

【カードの変更履歴を開く】
・カード詳細のヘッダーのボタンから、リストの移動や名前・説明・期限の変更など、カードの更新の記録を新しいタブで開けます（初期値 ON）
・記録は JSON 形式のまま、新しい順に最大1000件表示されます

【ショートカット「c」を無効化】
・入力中でないときにこのキーを押して、カードを誤ってアーカイブしてしまうのを防ぎます（初期値 OFF）
・押したときは、無効にしていることを画面右上に短く表示します。Ctrl+C などのほかのキー操作や、文字の入力には影響しません

■ 使い方
1. ツールバーのアイコンをクリックして、設定画面を開きます（マウスを重ねると「トレひろの設定」と表示）
2. スライダーとスイッチで調整します
3. 操作したその場で保存され、開いているタブにリロードなしで反映されます（保存ボタンはありません）

・「既定値に戻す」ボタンで初期値に戻せます
・設定画面上部の ON/OFF スイッチで、すべての機能を停止できます
・Chrome の同期（拡張機能）が有効なら、設定もほかの端末の Chrome に同期されます
・アイコンが見当たらないときは、ツールバーのパズルのピース型の「拡張機能」から開けます。ピン留めしておくと便利です
・インストール前から開いていたタブは、再読み込みすると有効になります

■ プライバシーと権限
・権限は、設定を保存する `storage` と、`trello.com` のページで表示を変えるためのアクセスだけです
・インストール時に、対象サイトのデータの読み取りと変更について確認が表示されます。表示の調整、ボタンやIDの表示、ショートカットの無効化に使います
・カードの色付けのため、カードのリンクパス、ラベルとカードの表示色、要素の大きさと属性、カバー画像の有無をブラウザ内で参照します
・ボタンを並べるため、「自動化」の一覧からボタンの名前とアイコンをブラウザ内で参照します。一覧は画面に出さずに開いて読み、すぐに閉じます
・リストIDの表示のため、各リストの枠に付いているIDの値をブラウザ内で参照します
・変更履歴のボタンは、アドレスバーのカードIDから記録のページのURLを作り、新しいタブで開くだけです。ページはブラウザが通常どおり読み込み、拡張自身は通信も、ページの内容の読み取りもしません
・ショートカットを止めるため、入力欄以外で押されたキーが修飾キーなしの「c」かどうかだけを判定します。キー入力は保存も送信もしません
・カードの名前・説明・コメントなどの文字は読みません
・参照した値はその場で使うだけで、保存も外部送信もしません
・外部サーバーとの通信、アクセス解析、外部からのプログラムの読み込みは行いません。設定の同期は Chrome の同期機能が行います
・保存するのは設定値10項目（全体の ON/OFF、幅、比率、ボタンの列の表示、色付けの ON/OFF、色の濃さ、鮮やかさ、IDの表示、履歴ボタンの表示、「c」の無効化）だけです
・ページに付けるのは拡張専用の印とボタンの列、ヘッダーのボタン2つ、リストIDの表示、キーを止めたときの通知だけです。ボードやカードのデータが変わるのは、表示したカードボタンを押したときだけです。その場合もサイト側の同じボタンを押して実行します

■ ご注意
・カード詳細を広げる機能は、ウィンドウ幅が750px以下のときは効きません（色付けは効きます）
・印刷には適用しません
・左右の比率は、コメント欄を開いているときに効きます
・ラベルのないカードと、カバー画像付きのカードは塗りません
・左端の帯に出るのは最大4色までです。それより多い色は帯に出ません
・カードボタンがないボードと、「自動化」を押せないカード（閲覧だけのボードなど）にはボタンの列は出ません。ボタンを追加・編集した後は、カードを開き直すと反映されます
・ページ内に埋め込まれた別の画面（iframe）の中には効きません
・サイト側の画面の仕組みが変わると、効かなくなる場合があります。そのときは設定画面上部のスイッチを OFF にすると、標準の表示に戻ります
