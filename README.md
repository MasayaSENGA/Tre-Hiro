# トレひろ – Trello ワイドカード

Trello のカード詳細（カードバック）を画面いっぱいに広げ、
**説明欄（左）とコメント欄（右）の比率**をポップアップから自由に調整できる Chrome 拡張機能です。
おまけとして、**ボードのカードをラベルの色で塗り分ける**こともできます。

Trello 標準ではカード詳細の幅が `584px`（コメント欄を閉じた状態）／`1080px`（開いた状態）に固定され、
説明欄側とコメント欄側のカラムに `min-width: 460px`、
さらに説明欄の内側に `max-width: 620px`、タイトルに `max-width: 544px` の制限があるため、
横に長い説明文や表が非常に読みにくくなっています。この拡張はその制限をまとめて解除します。

> トレひろは個人が開発した**非公式ツール**です。Trello および Atlassian とは提携・協力の関係になく、承認や推奨も受けていません。
> Trello は Atlassian の商標です。

## インストール

### Chrome ウェブストアから（通常はこちら）

1. [Chrome ウェブストアのトレひろのページ](https://chromewebstore.google.com/detail/mkggalenkddiimlbeipdnedgnpjonidi) を開く
2. **「Chrome に追加」** をクリック
3. ツールバーのパズルアイコンから「トレひろ」をピン留めしておくと便利です

### 開発用（未署名の拡張機能を読み込む）

ストアを使わずに開発中のコードを試すときは、このリポジトリを手元にクローンし、次の手順で読み込みます。

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパー モード** をオンにする
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. このフォルダ（`manifest.json` があるフォルダ）を選択

ストア版を入れている場合は、両方が同じページで動かないよう、ストア版をオフにしてから読み込んでください。

すでに Trello を開いている場合は、インストール（読み込み）後に一度リロード（F5）してください。

## 使い方

ツールバーの「トレひろ」アイコンをクリックすると設定パネルが開きます。

| 項目 | 内容 | 既定値 |
| --- | --- | --- |
| ON / OFF | 拡張の有効・無効。OFF にすると Trello 標準の見た目に戻ります | ON |
| カードの幅 | ウィンドウ幅に対するカード詳細の幅（40〜100%） | 95% |
| 左右の比率 | 説明欄側の割合（15〜90%）。残りがコメント欄 | 60 : 40 |
| カードの色付け | ボードのカードをラベル色で塗るか（この項目だけ個別に OFF にできます） | ON |
| （カードの色付けの）濃さ | 「カードの色付け」の下のスライダー（薄い〜濃い）。カードに重ねるラベル色の濃さ（5〜45%） | 16% |

スライダーを動かすと、開いている Trello のタブに**その場で反映**されます（リロード不要）。
設定は `chrome.storage.sync` に保存されるため、同じ Google アカウントでログインした
他の PC の Chrome にも同期されます（Chrome の同期が有効な場合）。

## 仕様・制限

- 対象は `https://trello.com/*` のページだけです（v2.0.1 までは `https://*.trello.com/*` も対象にしていました）。
  カードをモーダルで開いた場合・URL 直開き（`/c/xxxx`）の両方に適用されます。
- ウィンドウ幅 750px 以下では、Trello 自身が 1 カラム表示に切り替わるため何もしません。
- 印刷時（`@media print`）には適用されません。
- コメント欄（コメントとアクティビティ）を閉じている状態では、説明欄が自動的に全幅になります。
  コメント欄の開閉は、カード詳細の下に浮いているナビの「コメント」ボタンで行います。
- リストの幅には一切影響しません。
- カードの色付けは、カード全体にラベル色を薄く重ね、左端にラベル色の帯を出します。
  ラベルが複数付いている場合、帯は上から順に等分され（最大 4 色）、全面の色は 1 つ目のラベル色です。
- ラベルの付いていないカードと、カバー画像付きのカードは塗りません。
- 色付けは幅の調整と違い、ウィンドウ幅 750px 以下でも有効です。

## Chrome ウェブストアへの提出

アップロード用の ZIP は、リポジトリのルートで次のコマンドを実行すると `dist/tre-hiro-v<version>.zip` に作成されます（`dist/` は Git の管理対象外）。ZIP に入るのは、拡張機能の実行に必要なファイル（`manifest.json`、`*.js`、`*.css`、`popup.html`、`icons/`）だけです。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

macOS などで PowerShell を使わない場合は、同じ 11 ファイルの ZIP を `python3 store-assets/tools/package.py` でも作れます（出力は `dist/tre-hiro-<version>.zip`。中身の検証も行います）。

更新版を出すときは、`manifest.json` の `version` を公開中の版より大きくしてから ZIP を作り直します（表記は x.x.x にそろえます）。

## 実装メモ

Trello の CSS クラス名（`.mqI1p85XmC2MaW` など）はビルドごとに変わるハッシュ値なので、
`content.css` では以下のように**変わりにくい目印だけ**を使っています。

- カード本体 … `#layer-manager-card-back div[role="dialog"]` / `div[role="dialog"][data-testid="card-back-name"]`
- 説明欄側のカラム … その内側の `main`
- コメント欄側のカラム … その内側の `aside`
- コメント欄の開閉状態 … カード詳細の下に浮いているナビの「コメント」ボタン（`[data-testid="card-back-activity-button"][aria-checked]`）

比率は「`aside` に幅を与え、`main` を残り幅に縮ませる」方式で実現しています。
`main` 側に幅を指定していないため、コメント欄を閉じたとき（Trello 側で `main` が
`flex: 1 0 100%` に戻るとき）にも余白ができません。

要素やテキストの追加・削除・変更はせず、`<html>` と Trello のカードの要素に拡張専用の data 属性（`data-twc-*`）と
CSS 変数（`--twc-*`）を付けるだけなので、Trello の React 描画と干渉しにくくしています。

### カードの色付け

色名やクラス名はハードコードせず、**ラベルチップに実際に描画されている色**を
`getComputedStyle` で読んで借りています。Trello がパレット名（`green_subtle` など）を
変えても追従できます。塗りは `background-color` を上書きせず `background-image` の
半透明レイヤーとして重ねるので、ダークテーマでもホバー・選択状態でも破綻しません。

塗る対象は次の 2 段階で決めています。リンク `a[data-testid="card-name"]` は
**カードのタイトル行だけ**を包んでいて、カード全体ではないためです。

1. カード 1 枚ぶんの箱 … `[data-testid$="-card"]` / `…card-wrapper` / `…card-container`
   （見つからない Trello 版むけに、大きさを頼りに親をたどる保険あり）。ラベルはこの中から探す。
   カードの面を描く要素は `trello-card` だけでなく、他ボードへのリンクを含むカードは
   `mirror-card`、カバー付きは `full-cover-card` と種類ごとに `data-testid` が違うため、
   個別に並べず「`-card` で終わる `data-testid`」でまとめて拾っている
2. 実際に塗る要素 … その箱から「カードと同じ大きさで背景色を持つ、一番内側の要素」まで降りたもの。
   透明な入れ物に塗っても不透明な子要素に覆われて見えず、また Trello は同じ大きさの入れ子が
   両方とも同じ不透明色を持つことがあるので、背景色を見つけた最初の要素で止めてはいけない

## 動作確認

初版の開発時（2026 年 8 月）に、保存済みのカードページ（DOM）に対して、以下を実測して確認しています（ウィンドウ幅 1578px）。

| 設定 | カード幅 | 説明欄 | コメント欄 |
| --- | --- | --- | --- |
| OFF（Trello 標準） | 1080px | 460px (43%) | 620px |
| 95% / 60 : 40 | 1499px | 899px (60%) | 600px (40%) |
| 100% / 75 : 25 | 1570px | 1178px (75%) | 393px (25%) |
| 70% / 25 : 75 | 1105px | 276px (25%) | 828px (75%) |
| コメント欄を閉じた状態 | 1499px | 1499px (100%) | – |

※ OFF の行は初版時の記録のままです。2026 年 10 月に現行の Trello で測った標準は、説明欄 620px／コメント欄 460px（カード幅 1080px）で、説明欄とコメント欄の値が入れ替わっている可能性があります。

いずれも横スクロールは発生しません。

2026 年 10 月には、現行の Trello の公開ボードでも次を確認しています（ウィンドウ幅 1440px・1280px）。

- 既定の設定（95% / 60 : 40）で、カード幅が 95vw になり、説明欄とコメント欄が 60 : 40 に分かれる
  （1440px では 1368px = 820.8px + 547.2px）
- コメント欄を閉じると、説明欄が全幅になる
- ボードのカードがラベル色で塗られる（ラベルのないカードとカバー画像付きのカードは塗られない）
