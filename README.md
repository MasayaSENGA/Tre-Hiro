# トレひろ – Trello ワイドカード

Trello のカード詳細（カードバック）を画面いっぱいに広げ、
**説明欄（左）とコメント欄（右）の比率**をポップアップから自由に調整できる Chrome 拡張機能です。
おまけとして、**カードの自動化ボタン（カードボタン）をカード詳細の下部に常に並べる**ことと、
**ボードのカードをラベルの色で塗り分ける**こともできます。

Trello 標準ではカード詳細の幅が `584px`（コメント欄を閉じた状態）／`1080px`（開いた状態）に固定され、
説明欄側とコメント欄側のカラムに `min-width: 460px`、
さらに説明欄の内側に `max-width: 620px`、タイトルに `max-width: 544px` の制限があるため、
横に長い説明文や表が非常に読みにくくなっています。この拡張はその制限をまとめて解除します。

> トレひろは個人が開発した**非公式ツール**です。Trello および Atlassian とは提携・協力の関係になく、承認や推奨も受けていません。
> Trello は Atlassian の商標です。

## インストール

### Chrome ウェブストアから（通常はこちら）

1. [Chrome ウェブストアのトレひろのページ](https://chromewebstore.google.com/detail/mkggalenkddiimlbeipdnedgnpjonidi) を開く
2. **「Chrome に追加」** をクリック
3. ツールバーのパズルアイコンから「トレひろ」をピン留めしておくと便利です

### 開発用（未署名の拡張機能を読み込む）

ストアを使わずに開発中のコードを試すときは、このリポジトリを手元にクローンし、次の手順で読み込みます。

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパー モード** をオンにする
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. このフォルダ（`manifest.json` があるフォルダ）を選択

ストア版を入れている場合は、両方が同じページで動かないよう、ストア版をオフにしてから読み込んでください。

すでに Trello を開いている場合は、インストール（読み込み）後に一度リロード（F5）してください。

## 使い方

ツールバーの「トレひろ」アイコンをクリックすると設定パネルが開きます。

| 項目 | 内容 | 既定値 |
| --- | --- | --- |
| ON / OFF | 拡張の有効・無効。OFF にすると Trello 標準の見た目に戻ります | ON |
| カードの幅 | ウィンドウ幅に対するカード詳細の幅（40〜100%） | 95% |
| 左右の比率 | 説明欄側の割合（15〜90%）。残りがコメント欄 | 60 : 40 |
| 自動化ボタンを常に表示 | カード詳細の下部に、そのボードのカードボタン（自動化）を並べ、1 クリックで実行できるようにするか | ON |
| カードの色付け | ボードのカードをラベル色で塗るか（この項目だけ個別に OFF にできます） | ON |
| （カードの色付けの）濃さ | 「カードの色付け」の下のスライダー（薄い〜濃い）。カードに重ねるラベル色の濃さ（5〜45%） | 16% |

スライダーを動かすと、開いている Trello のタブに**その場で反映**されます（リロード不要）。
設定は `chrome.storage.sync` に保存されるため、同じ Google アカウントでログインした
他の PC の Chrome にも同期されます（Chrome の同期が有効な場合）。

## 仕様・制限

- 対象は `https://trello.com/*` のページだけです（v2.0.1 までは `https://*.trello.com/*` も対象にしていました）。
  カードをモーダルで開いた場合・URL 直開き（`/c/xxxx`）の両方に適用されます。
- ウィンドウ幅 750px 以下では、Trello 自身が 1 カラム表示に切り替わるため何もしません。
- 印刷時（`@media print`）には適用されません。
- コメント欄（コメントとアクティビティ）を閉じている状態では、説明欄が自動的に全幅になります。
  コメント欄の開閉は、カード詳細の下に浮いているナビの「コメント」ボタンで行います。
- リストの幅には一切影響しません。
- カードの色付けは、カード全体にラベル色を薄く重ね、左端にラベル色の帯を出します。
  ラベルが複数付いている場合、帯は上から順に等分され（最大 4 色）、全面の色は 1 つ目のラベル色です。
- ラベルの付いていないカードと、カバー画像付きのカードは塗りません。
- 色付けは幅の調整と違い、ウィンドウ幅 750px 以下でも有効です。
- 自動化ボタンは、カード詳細の下に浮いているナビの「自動化」で開く一覧（カードボタン）と同じものを、
  同じ順番・同じアイコンでカード詳細の一番下に並べます。押すと、そのボタンが実行されます
  （実行中はボタンのアイコンが回り、終わると Trello の「成功！」などの通知が出ます）。
  1 つ実行している間は、ほかのボタンは押せません。
- 一覧は、カード詳細を開くたびに「自動化」の一覧から読み取ります。開いた直後の一瞬（初回は 1 秒ほど）、
  ナビの「自動化」ボタンが押された見た目になりますが、一覧そのものは表示されません。
- ボタンの追加・編集は、これまでどおりナビの「自動化」から行います。追加・編集したボタンは、
  カードを開き直すか、ナビの「自動化」で一覧を開くと反映されます。
- カードボタンが 1 つもないボードと、「自動化」を押せないカード（閲覧のみのボードなど）には何も表示しません。

## Chrome ウェブストアへの提出

アップロード用の ZIP は、リポジトリのルートで次のコマンドを実行すると `dist/tre-hiro-v<version>.zip` に作成されます（`dist/` は Git の管理対象外）。ZIP に入るのは、拡張機能の実行に必要なファイル（`manifest.json`、`*.js`、`*.css`、`popup.html`、`icons/`）だけです。拡張機能のファイルを増やしたときは、`scripts/package.ps1` の `$files` と `store-assets/tools/package.py` の `ALLOWLIST` の両方に加えてください。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

macOS などで PowerShell を使わない場合は、同じ 12 ファイルの ZIP を `python3 store-assets/tools/package.py` でも作れます（出力は `dist/tre-hiro-<version>.zip`。中身の検証も行います）。

更新版を出すときは、`manifest.json` の `version` を公開中の版より大きくしてから ZIP を作り直します（表記は x.x.x にそろえます）。

## 実装メモ

Trello の CSS クラス名（`.mqI1p85XmC2MaW` など）はビルドごとに変わるハッシュ値なので、
`content.css` では以下のように**変わりにくい目印だけ**を使っています。

- カード本体 … `#layer-manager-card-back div[role="dialog"]` / `div[role="dialog"][data-testid="card-back-name"]`
- カード本体の直下で幅を決めているラッパー … その直下の `div` のうち、`main` を含むもの（`> div:has(main)`）
- 説明欄側のカラム … その内側の `main`
- コメント欄側のカラム … その内側の `aside`
- コメント欄の幅をドラッグで変えるつまみ … `main` の後ろにある `[role="slider"]`
- コメント欄の開閉状態 … カード詳細の下に浮いているナビの「コメント」ボタン（`[data-testid="card-back-activity-button"][aria-checked]`）

2026 年 10 月の Trello の更新で、カード詳細の固定幅（584px / 1080px）が `role="dialog"` の要素から
その直下のラッパー `div` に移りました（`dialog` 自体は `width: auto`）。`dialog` だけを広げると、
外枠は広がっても中身は 1080px のままになるので、ラッパーも `dialog` いっぱいに広げています。
`dialog` の直下には絶対配置の小さな `div` もあるので、`main` を含む子だけに絞っています。

比率は「`aside` に幅を与え、`main` を残り幅に縮ませる」方式で実現しています。
`main` 側に幅を指定していないため、コメント欄を閉じたとき（Trello 側で `main` が
`flex: 1 0 100%` に戻るとき）にも余白ができません。

同じ更新で、`main` と `aside` の間に、コメント欄の幅を 460〜620px の範囲でドラッグして変えるつまみ
（「ドラッグしてサイズを変更」）が加わりました。拡張が ON の間は `aside` の幅を拡張が決めていて、
つまみをドラッグしても幅が変わらないため、つまみを隠しています（OFF にすると元どおり表示されます）。

自動化ボタンの列（後述）を除き、要素やテキストの追加・削除・変更はせず、`<html>` と Trello のカードの要素に
拡張専用の data 属性（`data-twc-*`）と CSS 変数（`--twc-*`）を付けるだけなので、Trello の React 描画と干渉しにくくしています。
自動化ボタンの列も、拡張が作った要素を 1 つ、カード詳細の枠の最後に足すだけで、Trello が描いた要素は動かしません。

### カードの色付け

色名やクラス名はハードコードせず、**ラベルチップに実際に描画されている色**を
`getComputedStyle` で読んで借りています。Trello がパレット名（`green_subtle` など）を
変えても追従できます。塗りは `background-color` を上書きせず `background-image` の
半透明レイヤーとして重ねるので、ダークテーマでもホバー・選択状態でも破綻しません。

塗る対象は次の 2 段階で決めています。リンク `a[data-testid="card-name"]` は
**カードのタイトル行だけ**を包んでいて、カード全体ではないためです。

1. カード 1 枚ぶんの箱 … `[data-testid$="-card"]` / `…card-wrapper` / `…card-container`
   （見つからない Trello 版むけに、大きさを頼りに親をたどる保険あり）。ラベルはこの中から探す。
   カードの面を描く要素は `trello-card` だけでなく、他ボードへのリンクを含むカードは
   `mirror-card`、カバー付きは `full-cover-card` と種類ごとに `data-testid` が違うため、
   個別に並べず「`-card` で終わる `data-testid`」でまとめて拾っている
2. 実際に塗る要素 … その箱から「カードと同じ大きさで背景色を持つ、一番内側の要素」まで降りたもの。
   透明な入れ物に塗っても不透明な子要素に覆われて見えず、また Trello は同じ大きさの入れ子が
   両方とも同じ不透明色を持つことがあるので、背景色を見つけた最初の要素で止めてはいけない

### 自動化ボタン

2026 年 10 月時点の Trello では、カードボタン（Butler の自動化ボタン）はカード詳細の下に浮いているナビの
「自動化」（`button[aria-pressed]`）を押して開くポップオーバー（`.atlaskit-portal` の中の
`section[role="dialog"]`、ボタンは `ul > li > button`）の中にしかありません。

`autobuttons.js` は Trello や Butler の API を一切呼ばず、このポップオーバーを**見えない状態で開いて操作する**だけです。
並べたボタンは「代理」で、押されたら次の順に動きます。実行・権限の確認・成功／失敗の通知は Trello 自身が行います。

1. ナビの「自動化」を押してポップオーバーを開く（開いている間は `opacity: 0` と `pointer-events: none` で隠す）
2. 同じ名前のボタンを押し、Trello がボタンに出すスピナー（`[data-testid="spinner-wrapper"]`）が消えるまで待つ
3. 「自動化」をもう一度押して閉じ、ポップオーバーが奪ったフォーカスを元の場所に戻す

一覧の読み取りも同じやり方で、カード詳細を開いたときに 1 回だけ行います。次の点に注意しています。

- 「自動化」ボタンは、`aria-label`（「自動化」など）か、雷アイコンの SVG の形で見分けます。
  Power-Up ボタンを取り違えて押さないよう、ナビの中の位置では探しません
- `aria-pressed` はクリックした直後ではなく、次のマイクロタスクで `true` になります
- ページを開いて最初にポップオーバーを開いたときは、「`ul` はあるがボタンが 0 件」の状態が 0.3〜0.6 秒ほど続いてから
  一覧が届きます。この途中の状態はボタンが 1 つもないボードと見分けがつかないので、0 件のまま 1.5 秒たったら
  0 件とみなします。前にボタンが 0 件だったボードでは 0.4 秒で見切ります（Trello が一覧を覚えているときは、
  `ul` と同時にボタンが描かれるため）。ボードは、名前などの文字を読まずに、ボード画面の要素
  （`[data-testid="board-view"]`）そのもので見分けます
- ページから読むのは、ポップオーバーの中のボタンの名前とアイコン（の画像の URL）だけです。ページの通信や、
  カードの名前・説明・コメントは見ません。アイコンは、Trello が同じ一覧で表示しているのと同じ画像の URL を
  ボタンの背景に指定して表示します
- ポップオーバーは開くとフォーカスを奪い、中の「自動化を編集」などに入ります。操作中のキー入力でそれが押されないよう、
  ポップオーバーの中に届くキー操作は止めます。操作中にユーザーがどこかをクリックした場合は、Trello がポップオーバーを
  閉じるのに任せ、フォーカスも戻しません
- 入力欄やエディタに入力中のときは、フォーカスを奪わないよう、入力欄から離れるまで読み取りを待ちます
- ユーザーが自分で「自動化」を開いたときは、そのポップオーバーは隠さず、そこから一覧を読み直します

## 動作確認

初版の開発時（2026 年 8 月）に、保存済みのカードページ（DOM）に対して、以下を実測して確認しています（ウィンドウ幅 1578px）。

| 設定 | カード幅 | 説明欄 | コメント欄 |
| --- | --- | --- | --- |
| OFF（Trello 標準） | 1080px | 460px (43%) | 620px |
| 95% / 60 : 40 | 1499px | 899px (60%) | 600px (40%) |
| 100% / 75 : 25 | 1570px | 1178px (75%) | 393px (25%) |
| 70% / 25 : 75 | 1105px | 276px (25%) | 828px (75%) |
| コメント欄を閉じた状態 | 1499px | 1499px (100%) | – |

※ OFF の行は初版時の記録のままです。2026 年 10 月に現行の Trello で測った標準は、説明欄 620px／コメント欄 460px（カード幅 1080px）で、説明欄とコメント欄の値が入れ替わっている可能性があります。

いずれも横スクロールは発生しません。

2026 年 10 月には、現行の Trello の公開ボードでも次を確認しています（ウィンドウ幅 1440px・1280px）。

- 既定の設定（95% / 60 : 40）で、カード幅が 95vw になり、説明欄とコメント欄が 60 : 40 に分かれる
  （1440px では 1368px = 820.8px + 547.2px）
- コメント欄を閉じると、説明欄が全幅になる
- ボードのカードがラベル色で塗られる（ラベルのないカードとカバー画像付きのカードは塗られない）

2026-10-20 に、固定幅がラッパーに移った Trello の公開ボード（ログアウト状態）で、修正後の `content.css` を
ページに入れて次を実測しました。修正前は、カードの外枠だけが 1368px に広がり、中身は 1080px のまま
（説明欄 648px／コメント欄 432px）でした。

| 設定（ウィンドウ幅） | カード幅 | 説明欄 | コメント欄 |
| --- | --- | --- | --- |
| OFF（Trello 標準、1440px） | 1080px | 620px | 460px |
| 95% / 60 : 40（1440px） | 1368px | 820.8px (60%) | 547.2px (40%) |
| 100% / 75 : 25（1440px） | 1409.3px | 1057px (75%) | 352.3px (25%) |
| 70% / 25 : 75（1440px） | 1008px | 252px (25%) | 756px (75%) |
| 40% / 15 : 85（1440px） | 576px | 86.4px (15%) | 489.6px (85%) |
| 95% / 60 : 40（1024px） | 972.8px | 583.7px (60%) | 389.1px (40%) |
| コメント欄を閉じた状態（1440px） | 1368px | 1368px (100%) | – |

- カードをボードから開いた場合と、URL 直開き（`/c/...`）の両方で同じ値になる
- ON のときはドラッグ用のつまみが隠れ、OFF にすると表示される
- いずれも横スクロールは発生しない

同じ日に、自動化ボタンを、ログインした状態の Trello（カードボタン 8 個のボード、ダークテーマ、ウィンドウ幅 958px）で
確かめました。拡張機能としては読み込まず、`content.css` の該当部分と `shared.js`・`autobuttons.js` を
`chrome.storage` の代わりの小さな置き換えと一緒にページに入れて動かしています。

- カード詳細を開くと、ナビの「自動化」の一覧と同じ 8 個が、同じ順番・アイコンでカード詳細の一番下に並ぶ。
  ページを開き直した直後（Trello が一覧をまだ持っていない状態）でも、1 回の読み取りで並ぶ
- 並べたボタン（「全チェック」）を押すと、ポップオーバーは一度も見えないまま Trello のスピナーが約 1.2 秒回り、
  Trello の「成功！」の通知が出て、ポップオーバーが閉じる。フォーカスは押したボタンに戻る
  （この確認は、キー操作を止める処理と、0 件だったボードで待ち時間を短くする処理を足す前のコードで行いました。
  どちらも、ボタンを押してから閉じるまでの流れは変えていません）
- 読み取りの後、フォーカスはカード詳細に戻る。読み取りの最中にカード内をクリックしたときは、Trello がポップオーバーを閉じ、
  フォーカスはクリックした場所のまま
- ナビの「自動化」を自分で押したときは、ポップオーバーが普通に表示される
- 別のカードを開くと、そのカードで読み直して並べ直す
- 設定を OFF にするとボタンの列が消え、ON に戻すと読み直して並ぶ
- ポップアップの「自動化ボタンを常に表示」スイッチで、`autoButtons` が保存される（既定は ON）
